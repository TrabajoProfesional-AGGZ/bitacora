# Semana 23: Documentación integral, seguridad y entorno de Demo

**Período:** Jueves 13 de Agosto al Miércoles 19 de Agosto de 2026.

## 🎯 Objetivos de la semana

* [x] Asistir a la vigésimo primera reunión semanal.
* [x] Redactar la documentación técnica (C4 Model, DER, Anexos, manuales).
* [x] Construir un "club maqueta" con datos simulados para la demostración.
* [x] Finalizar y testear el bot conversacional ("BotIn").
* [x] Separar entornos de Firebase (Socios vs. Empleados).
* [x] Privatizar repositorios de back-end y crear repositorios públicos de documentación.
* [x] Crear el canal de YouTube de "SocioUnido".

## 📝 Tareas realizadas

* **Reunión semanal:** Asistencia a la clase regular con la cátedra, donde los tutores dieron la teoría de la "Promoción" en las empresas.
* **Fase documental:** Se dedicó la mayor parte de la capacidad del equipo a la creación de los diagramas arquitectónicos y la redacción de anexos (vistas, atributos de calidad, lecciones aprendidas).
* **Entorno de simulación:** Se configuró un club de prueba robusto que servirá como base exclusiva para la Demo oficial, asegurando que todos los módulos (tienda, eventos, cuotas) tengan información coherente.
* **Seguridad y DevOps:** Se logró separar exitosamente las apps en Firebase. Además, se ejecutó la privatización de los repositorios de back-end para proteger el código fuente, creando a la par repositorios públicos donde se migró toda la documentación vía JustTheDocs.
* **Audiovisual:** Se creó el canal de YouTube, que funcionará como hub centralizado de medios para el proyecto y futuras comunicaciones.

## 🚧 Problemas / Desafíos

* El proceso de duplicar los repositorios para mantener el código privado pero la documentación pública requirió un ajuste manual cuidadoso en las configuraciones de GitHub Pages, lo que supuso un pequeño reto de configuración DevOps, pero se resolvió sin impactos en el cronograma.
